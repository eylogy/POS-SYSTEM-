## How to Compile and Run

```bash
# Compile
g++ fp.cpp -o fp

# Run (Linux/macOS)
./fp

# Run (Windows)
fp.exe
```

You need a C++ compiler such as [g++](https://gcc.gnu.org/), or an IDE like Code::Blocks or Dev-C++.
